Experiencia garantizada en la total configuración y el manejo en directo de los siguientes equipos

Viz Flowics

  • Plataforma de creación de gráficos HTML5 basada íntegramente en la nube sin necesidad de hardware de renderizado local
  • Integración directa de datos en tiempo real incluyendo redes sociales, estadísticas deportivas y resultados financieros o electorales
  • Interfaz de diseño web intuitiva con funciones de arrastrar y soltar para la creación rápida de titulaciones y elementos broadcast
  • Compatibilidad nativa y transparente con múltiples sistemas de producción y mezcladores de vídeo profesionales mediante integración por URL
  • Control remoto multiusuario que permite a operadores deslocalizados gestionar y lanzar gráficos desde cualquier navegador web
  • Arquitectura escalable optimizada para producciones remotas (REMI) y generación de experiencias interactivas con la audiencia en directo

CGFootball

  • Sistema profesional de grafismo broadcast diseñado específicamente para la gestión de rotulación, marcadores y cronómetros en retransmisiones de fútbol
  • Integración avanzada de datos estadísticos en tiempo real mediante conexión directa con bases de datos oficiales y plugins de proveedores como Opta
  • Motor de renderizado multicapa que permite la emisión simultánea de múltiples elementos gráficos animados, alineaciones dinámicas y tercios inferiores
  • Reproductor integrado uPlayer multicanal para la emisión fluida de clips de vídeo, ráfagas de repetición y recursos publicitarios durante el encuentro
  • Alta flexibilidad de enrutamiento y entrada/salida de señal con soporte nativo para flujos de vídeo profesional mediante protocolos NDI, SDI y HDMI
  • Interfaz de operación optimizada para reacción inmediata en directo, con arquitectura robusta y redundancia para garantizar emisiones sin interrupciones

NewBlue Fusion

  • Sistema llave en mano para generación de gráficos broadcast 3D en tiempo real mediante el software NewBlue Captivate
  • Salida multicanal con soporte para hasta 16 canales NDI 4K y doble canal SDI (key/fill) mediante tarjetas Blackmagic Design
  • Integración nativa de datos en directo para vincular marcadores deportivos, hojas de cálculo, RSS y redes sociales
  • Incluye más de 1000 plantillas de titulación personalizables para producciones deportivas, noticias y entornos corporativos
  • Importación directa de proyectos y capas nativas desde Adobe Photoshop y After Effects sin necesidad de renderizado previo
  • Automatización de reproducción mediante API y soporte de controladores físicos externos para flujos de trabajo dinámicos

Cifras y Letras GFX

  • Aplicación creada y gestionada "ad hoc" para el programa de Televisión Española Cifras y Letras, mediante lenguajes de programación Python, Visual Basic
  • Integración con capa física al actuar sobre aparatos de hardware tales como DeckLink Studio, MIDI send/receive y protocolos de puerto que exigen apertura de puertos de red de routers mediante software de gestión PuTTY para actuar en consola
  • Distribución de múltiples señales vía IP para configuración del desarrollo del juego de cara a los concursantes y presentadores a través de apps creadas e integradas en entorno Windows y Android
  • Automatización de pantallas de puntuación por medio de programación vía IP

vMix GT Title

  • Aplicación nativa para diseño de titulación y gráficos animados en tiempo real acelerada por GPU
  • Arquitectura vectorial para garantizar nitidez absoluta de formas y textos en resoluciones hasta 4K
  • Motor de animación avanzada (In, Out, Continuous) mediante fotogramas clave sin sobrecargar la CPU
  • Integración dinámica con Data Sources de vMix para vincular datos externos desde Excel, XML, JSON y RSS
  • Importación directa de archivos de Adobe Photoshop (.PSD) conservando la estructura de capas
  • Reproducción multicapa fluida con canal alfa completo, optimizada para las versiones vMix 4K, Pro y Max
